# Geek roit — وب‌سایت تعاملی و اسکرول‌محور استودیو دیجیتال گیک رویت

وب‌سایت رسمی و تعاملی استودیو مهندسی و طراحی محصولات دیجیتال **Geek roit** با تمرکز بر چهار حوزه تخصصی:
- **طراحی سایت با وردپرس**
- **توسعه وب با React**
- **توسعه اپلیکیشن Android و iOS**
- **برنامه‌نویسی و راهکارهای هوش مصنوعی**

---

## ویژگی‌های کلیدی معماری و طراحی

1. **کاملاً فارسی و راست‌به‌چپ (RTL)**: استفاده از فونت استاندارد `Vazirmatn`، چیدمان بومی راست‌به‌چپ (`dir="rtl"`, `lang="fa"`) و رعایت کامل سلسله‌مراتب تایپوگرافی.
2. **تجربه اسکرول‌محور و صحنه ۳بعدی تعاملی (Three.js)**:
   - بخش نخست (Hero): صحنه سه‌بعدی «هسته دیجیتال گیک رویت» ساخته‌شده با مدل رویه‌ای چندبخشی (`THREE.Group`)، نورپردازی استودیویی PBR (`RoomEnvironment` + `ACESFilmicToneMapping`) و پنل کنترل جمع‌شونده در پایین صفحه.
   - بخش دوم (از ایده تا محصول): دگردیسی ۴ مرحله‌ای هماهنگ با موقعیت اسکرول کاربر.
   - بخش سوم (خدمات): چیدمان تعاملی چهار سرویس اصلی با قابلیت بررسی جزئیات.
   - بخش چهارم (فرآیند توسعه): خط زمانی ۵ مرحله‌ای (افقی در دسکتاپ و عمودی در موبایل).
   - بخش پنجم (نمونه‌کارها): وضعیت طراحی‌شده و صادقانه «در حال بارگذاری نمونه‌کارها...» با کارت‌های مفهومی «به‌زودی» بدون پروژه‌های ساختگی، همراه با قابلیت تغییر به حالت انتشار پروژه‌های واقعی از پنل ادمین.
   - بخش ششم (چرا Geek roit): ارزش‌های مهندسی و تعهدات کیفی بدون آمارهای ساختگی.
   - بخش هفتم (پایان و شروع پروژه): فرم ثبت درخواست با اعتبارسنجی دقیق و نمایش شماره تماس قابل تنظیم.
3. **پنل مدیریت یکپارچه (`/admin`)**:
   - `/admin/content`: ویرایش نام برند، تیترها، متون صفحه و امضای فوتر (`درست شده توسط شرکت گیک رویت`).
   - `/admin/services`: ویرایش عناوین و توضیحات خدمات.
   - `/admin/projects`: کلید تغییر وضعیت «نمایش حالت در حال آماده‌سازی» و افزودن/انتشار/مرتب‌سازی پروژه‌های واقعی.
   - `/admin/theme`: تغییر رنگ‌های اصلی و فرعی، سبک دکمه‌ها و شدت انیمیشن.
   - `/admin/contact`: تنظیم شماره تماس اصلی و جایگزین، ایمیل، لینک‌های شبکه‌های اجتماعی و انتخاب محل نمایش شماره (هدر، فوتر، بخش پایانی).
   - `/admin/settings`: مشاهده درخواست‌های ثبت‌شده، مستندات امنیتی و بازنشانی تنظیمات.

## دستورات اجرای محلی (Local Development)

پیش‌نیاز: نصب بودن **Node.js** (نسخه ۱۸ یا بالاتر).

```bash
# ۱. نصب وابستگی‌ها
npm install

# ۲. اجرای سرور توسعه (روی پورت 3000)
npm run dev

# ۳. اجرای تست‌های واحد منطق و اعتبارسنجی
npx tsx --test src/utils/validation.test.ts

# ۴. بررسی خطاهای تایپ‌اسکریپت
npm run lint

# ۵. ساخت نسخه نهایی تولید (Production Build)
npm run build
```

## شفافیت امنیتی و محدودیت‌های نسخه نمایشی (Frontend Demo)

- این برنامه به‌گونه‌ای طراحی شده است که بدون نیاز به سرور یا کلیدهای پایگاه داده، به‌صورت کاملاً مستقل روی سرویس‌های میزبانی استاتیک قابل استقرار باشد.
- در حالت پیش‌فرض (`LocalDemoRepository` در فایل `src/store/ConfigContext.tsx`)، تغییرات پنل مدیریت و فرم‌های ثبت درخواست در `localStorage` مرورگر ذخیره می‌شوند.
- **نکته امنیتی مهم**: ذخیره‌سازی در مرورگر (`localStorage`) صرفاً جهت پیش‌نمایش و دمو است و جایگزین احراز هویت سمت سرور نیست. هیچ رمز عبور، کلید خصوصی (Service Role Key) یا داده حساسی در مرورگر ذخیره نمی‌شود.
- برای محیط عملیاتی چندکاربره، رابط `ConfigRepository` آماده اتصال به **Supabase** (همراه با Supabase Auth و Row Level Security) یا API اختصاصی سمت سرور است.

## راهنمای استقرار (Deployment) در Netlify و Vercel

### استقرار در Netlify
1. مخزن پروژه را به حساب Netlify خود متصل کنید یا پوشه `dist` را بارگذاری نمایید.
2. تنظیمات Build:
   - **Build Command**: `npm run build`
   - **Publish Directory**: `dist`
3. فایل `public/_redirects` به‌طور خودکار در خروجی قرار می‌گیرد تا مسیرهای React Router (مانند `/admin/contact`) بدون خطای 404 باز شوند.

### استقرار در Vercel
1. پروژه را در Vercel ایمپورت کنید (Framework Preset: **Vite**).
2. تنظیمات Build:
   - **Build Command**: `npm run build`
   - **Output Directory**: `dist`
3. فایل `vercel.json` در ریشه پروژه، هدایت مسیرهای SPA به `/index.html` را تضمین می‌کند.
